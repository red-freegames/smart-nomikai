# 酒と泪と男と女〜スマート飲み会シミュレーター〜

お酒の失敗を防ぎつつ、スマートに飲み会を生き残る啓発型シミュレーションゲーム。
1ファイル（`index.html`）で動くブラウザゲームです。

▶ **遊ぶ：https://red-freegames.github.io/smart-nomikai/**

## あそびかた
- 19:00〜翌朝8:00まで、全7軒をハシゴ。1軒につき3ターン。
- 1ターン＝🍺ドリンク → 🍢フード → 🙋行動 を1つずつ選ぶ。
- 🍺酔い度は隠しパラメータ。トイレの鏡・画面の揺れ・心の声で「引き際」を見極めよう。
- 🎉盛り上がりが店の必要ラインを下回るとお開き。100%酔うとGAME OVER。
- 朝8時まで完走で完全クリア（スコア2倍）。

※このゲームはフィクションです。お酒は20歳になってから。飲酒の強要はアルハラです。
